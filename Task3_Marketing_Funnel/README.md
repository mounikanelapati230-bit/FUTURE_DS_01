# 📊 Task 3 - Marketing Funnel Analysis
## 📌 Project Overview
This project analyzes user movement through different stages of a marketing funnel using Excel.  
The main objective is to understand user behavior, identify drop-off stages, and calculate conversion rates between different funnel stages.
---
## 🗂️ Dataset Used
The dataset contains user activity data for the following funnel stages:
- 🏠 Home Page
- 🔍 Search Page
- 💳 Payment Page
- ✅ Payment Confirmation
Each dataset contains user IDs and page names for analysis.
---
## 🛠️ Tools & Technologies Used
- 📑 Microsoft Excel / WPS Office
- 📊 Pivot Tables
- 📈 Charts & Graphs
- 🧮 Conversion Rate Calculations
- 📋 Data Cleaning & Analysis
---

## 🧮 Conversion Rate Calculations
| Stage | Formula | Result |
|-------|---------|--------|
| 🔍 Search Conversion | 45200 / 90400 × 100 | 50% |
| 💳 Payment Conversion | 6030 / 45200 × 100 | 13.30% |
| ✅ Final Conversion | 452 / 6030 × 100 | 7.50% |

## 🔍 Insights
- 🏠 Home Page has the highest number of users (90,400).
- 🔍 Around 50% of users moved from the Home Page to the Search Page.
- 💳 Only 13.30% of users reached the Payment Page.
- ✅ Final conversion rate is only 7.50%.
- 📉 Major user drop-off occurs before payment confirmation.
- 🚀 Improving payment experience and user flow may increase conversions.
---
## ✅ Conclusion
This marketing funnel analysis helps identify user drop-off stages and overall conversion performance.  
The analysis shows that user engagement decreases significantly after the search stage.  
Improving the payment process, user interface, and customer experience can increase final conversions and business growth. 📈🚀
